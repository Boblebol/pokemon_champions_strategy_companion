# Maquette mobile

`maquette_v1/standalone_version_html.html` est la référence fonctionnelle pour
le comportement tactile Team, Build, Actifs et Match. Les fichiers JSX à côté
du HTML exposent la même structure avec des blocs plus lisibles pour comparer
les écrans pendant les passes d'intégration.

La vraie app React doit rester branchée sur les données locales, les exports et
les calculs existants. La maquette sert uniquement de source d'alignement visuel
et d'interaction.
