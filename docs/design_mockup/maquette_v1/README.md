# Maquette mobile v1

`standalone_version_html.html` est la référence visuelle validée pour le shell
mobile. Les fichiers JSX voisins sont la version lisible de cette maquette et
servent de contrat pour les espacements, la navigation, les slots, les chips de
types, les détails avancés et les écrans `Team`, `Build`, `Actifs`, `Match`.

L'app réelle reprend cette structure, mais remplace les données figées de la
maquette par la référence locale Pokémon Champions : Pokémon légaux, talents,
objets, natures, types Tera et attaques compatibles avec le Pokémon choisi.
Les écarts acceptés doivent être liés à cette logique métier ou à l'accessibilité
des contrôles réels, pas à une variation visuelle gratuite.
